## Contexte

Maquette « Ajout » (§15.4), spec §6, §7.3.

## Critères d'acceptation

- [x] Feuille basse depuis un module libre : type, libellé, calibre, largeur (stepper)
- [x] Types dont la largeur ne tient pas grisés ; dépassement refusé
- [x] Formulaire « Autre appareil » (nom, rôle, marque, modèle, modules) et enregistrement du modèle personnalisé
- [x] Photo facultative
