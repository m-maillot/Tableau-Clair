## Contexte

Maquette « Ajout » (§15.4), spec §6, §7.3.

## Critères d'acceptation

- [ ] Feuille basse depuis un module libre : type, libellé, calibre, largeur (stepper)
- [ ] Types dont la largeur ne tient pas grisés ; dépassement refusé
- [ ] Formulaire « Autre appareil » (nom, rôle, marque, modèle, modules) et enregistrement du modèle personnalisé
- [ ] Photo facultative
