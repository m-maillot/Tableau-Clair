## Contexte

Spec §15. Tokens en variables CSS, Plus Jakarta Sans, composants atomiques.

## Critères d'acceptation

- [ ] Tokens `ink`, `blue`, `lime`, `surface`, `bg-soft`, `muted`, `module-other`, `slot-border`, statuts
- [ ] `StatusChip` (icône + libellé), `TabBar`, `BottomSheet`, `TypeChip`, `Stepper`, boutons et champs
- [ ] Zones tactiles ≥ 44 px, contrastes AA, `aria-label` sur les boutons-icônes
- [ ] Catalogue de composants (Storybook ou page interne)
